# AGENTS.md — ISO Master

Agent instructions for working in this repository.

## Project

ISO Master is a graphical CD image editor for Linux/BSD. It is built as a GTK4 + libadwaita GUI application written in Vala, backed by the pure-C `bkisofs` library in `bk/`.

> **Important:** The existing `CLAUDE.md` describes the old GTK2/C frontend and is outdated. Trust `Makefile.vala` and `README.md` for the current stack.

## Build system

Use the Vala makefile explicitly; there is no top-level `Makefile`:

```bash
make -f Makefile.vala
```

Dependencies: `gcc`, `make`, `valac`, `gtk4-devel` / `libgtk-4-dev`, `libadwaita-devel` / `libadwaita-1-dev`, `gettext`, `pkg-config`.

Build artifacts:

- `isomaster` — final executable
- `isomaster.c` — generated C from `isomaster.vala`; not tracked in git (regenerated by the build)
- `iconpath.c`, `iconpath.h` — generated icon-path stubs
- `bk/bk.a` — static bkisofs library
- `iniparser-4.1/libiniparser.a` — bundled INI parser library

Install / uninstall:

```bash
sudo make -f Makefile.vala install
sudo make -f Makefile.vala uninstall
```

You can run `./isomaster` from the build tree; icons are only available after install.

## Architecture

- `isomaster.vala` — entire GTK4/Adwaita application (single file)
- `bk/` — pure-C ISO manipulation library (`bk.a`); has no GTK dependency
- `bk.vapi` / `iniparser.vapi` — Vala bindings for the C libraries
- `iniparser-4.1/` — bundled INI parser used for settings
- `po/` — gettext translations (compiled to `.mo` during build)
- `icons/` — application icons
- `tests/` — unit tests for the `bk` library
- `scripts/gtk4/isomaster-gtk4.spec` — RPM spec used by CI

## Testing

Run the `bk` library unit tests:

```bash
cd tests && ./run_tests.sh
# or directly:
make -C tests
make -C tests test
```

Tests compile `../bk/bk.a` if needed, run `./test_bk`, and clean up `/tmp/test_bk_*` artifacts.

## CI / Packaging

- `.github/workflows/rpm.yml` builds RPMs on Fedora 43/44 and EL10 (x86_64 and aarch64) for `main`/`gtk4` branches and version tags.
- It uses `scripts/gtk4/isomaster-gtk4.spec` and excludes generated files (`*.o`, `isomaster.c`, `isomaster`) from the source tarball.

## Coding conventions

- GUI: Vala with GTK4/Adwaita APIs (`Adw.Application`, `Gtk.ListView`, etc.)
- Backend library: C99 (`-std=gnu99`) with `_FILE_OFFSET_BITS=64`
- Translations: use the `_t()` helper in Vala, backed by `dgettext("isomaster", ...)`
- Keep `bk/` free of GTK/GLib dependencies

## Handy commands

```bash
# Full build
make -f Makefile.vala

# Run from build tree
./isomaster

# Run backend unit tests
cd tests && ./run_tests.sh

# Clean
make -f Makefile.vala clean
```
